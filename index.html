Data Structures Assignment: Maps and More Maps

Author: anonymous

Part 1 Assignment Description:

The initial assignment asks students to use Java's built-in Map data structure to organize television shows by
the number of seasons they have aired and to practice adding, accessing, and modifying entries in the map.
Students must implement the following activities as part of this assignment:

    ACTIONS FOR TV SHOW MAP
  • A: Add a Show
  • D: Delete a Show
  • K: Print All Keys (Durations) to the Report File
  • P: Print Map Listing to the Report File
  • S: Print Specific Key Values (All shows with the provided duration) to the Report file
  • Q: Quit

There is a data file provided for this assignment, but minimal starter code.
Students are expected to provide a well organized, modular program where each method includes pre- and post- conditions that clearly explain the purpose of each method.
To submit this assignment, students will provide a video demonstrating their code running through a provided testing script and must answer the following questions:

  • Ask an LLM to identify any missing testing scenarios from the script provided and describe these issues
  • Demonstrate 1 of these tests in your video and show how your program handles this scenario
  • Discuss any other testing issues we may have missed – do you think your program would handle these successfully

Part 2 Assignment Description:

The second assignment comes later in the semester. It utilizes the same basic program as Part 1, but requires the student to replace the built in Map data structure with
MyHashMap data structure developed as part of the lecture class and add logic to verify missing testing scenarios from Part 1.
Prior to providing this assignment, students learn about hash maps and implement some of the methods needed for this data structure to work using chaining. Chaining is implemented
using MyLinkedList, a data structure previously built in the course. To complete the data structure, students are asked to choose 1 of the 4 missing methods
and provide the pseudocode for the method chosen.
Once this step is completed, students will compare their logic with an LLM and ensure they have not missed any key logic. Then, students will work in small groups to explain their logic to others.
Time permitting, one method is chosen and student volunteers are asked to provide the code for that method.

Metadata

Summary The first assignment is given early in the semester and is designed to review Java concepts through the use of the built-in Map data structure.
The second assignment builds on this foundation by requiring students to implement their own version of a Map, helping them develop a deeper understanding of how the data structure works in Java.
Audience These assignments are part of the Data Structures course where students have previously programmed in Java.
Difficulty The first assignment is review and is generally considered easy for students to complete. The second assignment requires that students have completed a series of other data structure
during the course of the semester and then must complete the MyHashMap data structure. This assignment should be moderately challenging.
Length The first assignment is done mainly outside of class after a quick discussion regarding Java Maps.
The second assignment follows 1-2 50-minute lecture(s) on programming hash tables.
The in-class exercise to write the missing methods takes about half of a 50-minute lecture period.
Students are given a week to complete the coding for the second assignment.
Strengths There are several aspects of these assignments that make them particularly useful:
  • Both assignments incorporate LLMs to help students explore how these tools can support the programming process.
    In the first assignment, students use an LLM to identify missing test cases.
    In the second, they use an LLM to compare their own implementation and reasoning with alternative approaches.
  • Students gain experience modifying existing code to meet new requirements, which is an important part of real-world software development.
  • Because the assignments revisit similar concepts at different points in the semester, students can see how their programming skills and understanding have developed over time.
Weaknessess Students submit their work via video. They demonstrate their program running and show the testing scenarios from the test script.
Sometimes, these videos are very long!
Dependencies Throughout the semester, students are building the underlying data structures for this project. These include building the structures:
MyList, MyLinkedList, MyArrayList and MyMap and MyHashMap. If students do not have one or more of these completed, this project cannot be completed.
If using another language, please note that the underlying linked list data structure needs to be completed prior to giving students this assignment.
Starter code for these assignments was provided to students using GitHub Classroom. These links were removed as the starter code
Variants This assignment can be modified for any programming language.
The teaching method: Think-(review LLM)-Pair-Square-Share can be used for the 4 missing methods so that students leave with the pseudocode for all 4 of the missing methods.
Currently, students choose the method they work on based on difficulty, which provides a level of scaling for student ability.
